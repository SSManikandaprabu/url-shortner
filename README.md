## ✨ Overview

**LinkPulse** is a modern, responsive web application designed for developers and project maintainers. It allows you to instantly shorten URLs, track click analytics, generate downloadable QR codes, and automatically compile active links into clean, GitHub-ready markdown badges and tables for your project `README.md` files.

Best of all? It runs entirely in the browser with zero backend setup required, utilizing `localStorage` for seamless persistence.

---

## 📸 Features

*   **⚡ Instant URL Shortener**: Shorten any long URL instantly with auto-generated alphanumeric codes or custom user-defined aliases.
*   **📊 Analytics Dashboard**: Track click counts, view top-performing links, and analyze simulated traffic and device breakdowns.
*   **🏷️ README Markdown Studio**: Automatically formats all your shortened links into Shields.io badges and markdown tables that you can copy straight into your documentation.
*   **📱 QR Code Generator**: Generate and download high-resolution QR codes for any short link on the fly.
*   **🔄 Redirection Simulator**: Safe redirect preview modal to test links before visiting destinations.
*   **🎨 Sleek Dark Mode UI**: Built with Tailwind CSS and FontAwesome icons for a polished, developer-first aesthetic.

---

## 🛠️ Tech Stack

*   **Frontend**: HTML5, Vanilla JavaScript (ES6+)
*   **Styling**: Tailwind CSS (via CDN)
*   **Icons**: Font Awesome 6.4.0
*   **QR Generation**: `qrcode.min.js`
*   **Storage**: Browser `localStorage`

## 🚀 Quick Start / Installation

Because LinkPulse is built as a **single-file application**, running it locally or deploying it takes seconds!

1. **Clone or Download** this repository:
   ```bash
   git clone https://github.com/your-username/link-pulse.git
   ```
2. **Navigate** into the project folder:
   ```bash
   cd link-pulse
   ```
3. **Open `index.html`** in any modern web browser:
   * Double-click the `index.html` file, or
   * Run it using a local live server (e.g., Live Server extension in VS Code).

---

## 💡 How to Use

1. **Create Short Links**: Paste your destination URL on the main dashboard. Open **Advanced Options** to specify a custom alias or categorization tag.
2. **Monitor Clicks**: Switch to the **Analytics** tab to view your top links and click distribution.
3. **Generate README Snippets**: Head over to the **README Generator** tab to customize your project title, badge styles, and instantly copy your markdown code directly into your repository documentation.
